# 复旦MBA 凤凰3班 · 2026级

手机优先的班级信息网站，橙色 Banner、正式凤凰 Logo 与“橙启新序，共赴同行”口号。课程、作业、活动、公告和资料通过飞书多维表格统一维护。没有学生登录、个人作业完成状态或个人报名功能。

## 开始使用

面向班委的完整说明在 `docs/飞书接入与上线.md`。先将 `templates` 下五份 CSV 导入一个飞书多维表格，再配置只读应用和 Netlify Functions 环境变量。当前未连接真实表格，页面明确显示示例状态。

## 文件结构

- `dist/`：H5 页面、样式、官方 Logo、示例内容和前端同步逻辑。
- `server/feishu.mjs`：只读飞书接口，鉴权、分页、字段校验、发布过滤及缓存。
- `netlify/functions/class-content.mjs`：Netlify Functions 入口，`/api/class-content`。
- `netlify.toml`：完整站点的发布配置。此次不能再只拖拽 dist 发布后台。
- `.env.example`：服务器变量样例，不含任何真实凭证。
- `templates/`：可导入飞书的五份 CSV，所有示例默认草稿。
- `docs/飞书接入与上线.md`：建表、授权、上线、日常维护与故障说明。
- `tests/`：接口行为、发布过滤、异常状态、真实日期和前端内容隔离验证。

## 本地运行

需要 Node.js 22 或更高版本。无第三方运行依赖。

`npm start`：启动 `http://127.0.0.1:4317`，提供页面和后台接口。可复制 `.env.example` 为本地 `.env` 后自行填写变量，不要提交真实 `.env`。

`npm test`：运行模拟接口及前端状态测试。

`npm run check`：检查入口文件语法。

直接打开 `dist/index.html` 或使用原来的静态预览服务也能查看示例页面；静态服务不能提供真实飞书同步。

## 发布与数据

推荐 GitHub 仓库连接 Netlify，发布整个项目。App Secret 仅通过 Netlify 环境变量注入 Functions。后台只读取授权表格，不写入飞书；仅返回“已发布”行的预设展示字段。

后台缓存5分钟，页面每5分钟自动检查一次；最迟通常约10分钟反映变更。只读错误时不返回过期快照，前端也不会退回未标注的模拟数据。缺少全部凭证时返回示例状态，部分配置或权限错误时返回明确的不可用状态。真实连接仍需用户建表、授权和部署后验证。

官方 Logo 源于班级提供的 Illustrator 文件，保留原始图形、渐变及内嵌图层。原始文件未修改。班级人数、成员和学习小组未接入飞书；正式模式不会显示虚构同学。
