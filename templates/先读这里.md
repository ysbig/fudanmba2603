# 凤凰3班飞书导入模板

这五份 UTF-8 CSV 用于导入同一个飞书多维表格中的五张数据表。第一行是字段名，请选择“首行作为字段名”，不要改名或删除列；可以自行增加额外列，网站不会读取额外列。

文件依次为：01_课程、02_作业、03_活动、04_公告、05_资料。每份含两条明确标注的示例记录，全部为“草稿”。示例来自本网站的模拟数据，不是学校正式安排。联系人均为模拟姓名。替换成真实内容后，再改为“已发布”。

导入后推荐设置：

- 发布状态：单选，选项为“草稿”“已发布”“已下架”。只有“已发布”会显示。
- 日期及含时间的日期：可保留文本，也可改为飞书“日期”字段。日期示例 `2026-09-17`；日期时间示例 `2026-09-17 23:59`。填写和显示都按北京时间，含截止时间的字段应开启“包含时间”。
- 课程表的开始时间、结束时间：保持文本，格式 `18:00`、`21:30`，一行代表一天的一节课；不要改成日期字段。
- 参加人数：数字、整数，允许 0，范围 0–9999。
- 发布人、对接人姓名、对接方式：保持文本，不要改成“人员”或“关联”字段。
- 资料链接：文本或超链接字段，必须填写完整 `https://` 网址。示例留空，发布前填写真实文档地址。附件字段暂不直接读取；请填写资料分享链接。
- 分类、课程类型和活动类型：文本或单选。资料分类建议为“课件”“案例”“班级资料”。
- 长文本内容完整保存在 CSV 单元格内；导入飞书后可展开单元格阅读，不要按其中的换行拆成多行记录。

发布前必须填写：

| 表 | 必填字段 |
| --- | --- |
| 课程 | 课程名称、课程代码、日期、开始时间、结束时间、授课教师、上课地点、发布状态 |
| 作业 | 作业标题、课程名称、课程代码、截止时间、作业要求、提交说明、发布人、发布时间、发布状态 |
| 活动 | 活动名称、活动简介、开始时间、结束时间、活动地点、参加人数、活动内容、对接人姓名、对接方式、发布人、更新时间、发布状态 |
| 公告 | 公告标题、正文、发布人、发布时间、发布状态 |
| 资料 | 资料名称、课程名称、课程代码、分类、资料链接、更新时间、发布状态 |

同一课程在“课程”“作业”“资料”中的课程代码请保持一致，例如 DMD。网站用它关联资料入口。所有列名都要保留，即使该列允许不填。

发布顺序：补齐内容 → 检查时间地点 → 改为“已发布”。撤回时改为“草稿”或“已下架”。通常几分钟更新，缓存与网页检查叠加时最长约10分钟。表格只分享给负责维护的同学并授予编辑权限；网站只公开上述已发布字段。
